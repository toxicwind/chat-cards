# Chat Cards Plugin with Pattern Forge Integration

Interactive card deck for GitHub Copilot canvas that goes beyond basic visualization to include hyper-integrated pattern-forge capabilities. Instead of walls of text, the agent explains things visually with a live deck of interactive cards that seamlessly integrate pattern discovery, instantiation, composition, and application.

## Features

- **Tab boxes**: Interactive tabbed sections for organizing pattern information
- **Tables**: Structured displays of pattern types and their characteristics
- **SVG charts**: Visual representations of pattern relationships and structures
- **Forms**: Two-way data collection for pattern parameter configuration
- **Collapsible sections**: Hierarchical pattern library organization
- **Numbered outlines**: Structured pattern workflow guidance
- **Rendered markdown documents**: Detailed pattern documentation and examples
- **Short video clips**: Pattern application demonstrations
- **Pattern Forge Integration**: Direct access to pattern instantiation and application capabilities

## Pattern Forge Capabilities

This enhanced version includes specialized cards for pattern-forge workflows:
- Pattern discovery and browsing
- Pattern instantiation with parameter forms
- Pattern visualization and diagramming
- Pattern application to codebases
- Pattern library management

## Installation

```bash
copilot plugin install chat-cards@awesome-copilot
```
